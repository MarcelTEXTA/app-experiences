# app-experiences
This is a simple repo to publish my experience with Qt and Juce with C++.

There are :

- **Note Pad** : a simple notepad to write text and save it in a file. It is made with Qt.
- **Audio Player** : a simple audio player to play audio files. It is made with Juce.
- **Audio Recorder** : a simple audio recorder to record audio from the microphone. It is made with Juce.
- **Calculator** : a simple calculator to perform basic arithmetic operations. It is made with Qt.
- **To Do List** : a simple to do list to manage tasks. It is made with Qt.

## Installation
To run the applications, you need to have Qt and Juce installed on your system. You can download them from their official websites. Once you have them installed, you can clone this repository and open the projects in Qt Creator or other IDEs to build and run the applications.
